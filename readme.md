# EAGOS 5.0.0

**Evidence-led Agent Governance and Operations System**

*From intent to governed action.*

EAGOS governs how people and agents turn intent into verified outcomes. Its compact contract and shared Python rules keep evidence, responsibility and authority clear while useful work proceeds within agreed limits.

Read [the governance contract](eagos.md) alongside the current initiative and its applicable authority. Start with the smallest useful action; add records only when they improve decisions, execution or continuity.

CICADA is an enterprise environment that applies EAGOS. The framework remains reusable across organizations and software.

[Source provenance](sources.md) identifies the rewrite’s foundation. Run `python3 -m unittest discover -s tests -v` and `python3 check.py` to check the library and documents. These checks do not establish operational enforcement.
