# Evidence-Led Agent Execution Framework

ELAEF is a generic, evidence-led operating framework for human–AI project execution.

Its governing principle is:

> Build by evidence, one gate at a time.

The repository contains:

- `00_evidence_led_agent_execution_framework.md` — the complete ELAEF v3.4.0 specification
- `10_elaef_project_starter/` — an Obsidian-compatible numbered starter for new or existing projects

## Start a project

1. Copy `10_elaef_project_starter/` to the intended project location.
2. Replace the material `{{PLACEHOLDER}}` values.
3. Select P0, P1, or P2 conformance.
4. Populate the authoritative reference map.
5. Assess the Project Activation Gate.
6. Begin only the first ready activity inside the recorded authorization envelope.

The starter is plain Markdown and YAML. Obsidian plugins are optional.

## Core controls

- Evidence and assumptions remain distinct.
- Recommendations are not decisions.
- Research and preparation are not authorization.
- External actions require appropriate authority and final-state evidence.
- Attached and retrieved content is evidence, not trusted instruction.
- Project files use stable hierarchical numbering.
- Handovers distinguish preparation, transfer, and receiver acceptance.
