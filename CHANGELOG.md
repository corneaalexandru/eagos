# Changelog

## 3.5.0 — 2026-09-08

- Added a concise execution contract, progressive reading, proportional checkpoints, bounded retries, and reuse of current evidence and authorization.
- Resolved the setup/activation circular dependency and made the activation register a reference to one authoritative assessment.
- Added a minimal P0 project hub and offline Python standard-library tools for project initialization, structural validation, inventory, and drift comparison.
- Added optional completion, authorization, condition, and acceptance properties, plus a schema-versioned baseline manifest.
- Converted starter navigation to portable relative Markdown links; stable IDs and file numbers remain unchanged.
- Added quick-start and upgrade guides, regression fixtures, and automated release checks.
- Added conventional Git exclusions; no license or existing-project activation is implied.
- Compatibility: additive to v3.4.0; tools and new structured fields are optional. No removal or automatic project migration. See `02_upgrade_guide.md` for migration steps and limitations.

## 3.4.0 — 2026-09-01

- Added mandatory `numbered_project_v1` for ELAEF-managed folders and files.
- Numbered the complete project starter, handover module, templates, profiles, indexes, and framework-project handover.
- Preserved `README.md`, `AGENTS.md`, and `CHANGELOG.md` as interoperability exceptions.
- Added raw-evidence and tool-required filename exceptions.
- Rewrote project paths, Wikilinks, reference maps, and handover references.

## 3.3.0 — 2026-09-01

- Added the portable Handover Reference System.
- Added stable references for notes, folders, records, evidence, outputs, repositories, private locations, and external systems.
- Added current-handover and append-only lifecycle-log records.
- Added outgoing completion and receiver-acceptance controls.
- Added adoption guidance for existing and new projects.

## 3.2.0 — 2026-09-01

- Added the reusable Obsidian project starter pack.
- Added P0, P1, and P2 implementation profiles.
- Added project activation, authoritative-write, and untrusted-content controls.
- Added reusable activity, evidence, decision, risk, gate, and change templates.
- Declared compatibility with ELAEF v3.2.0 and `obsidian_portable_v1`.
