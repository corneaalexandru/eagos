# Contributing

Keep changes small and evidence-led. Explain the problem, expected behavior and meaningful verification. Use synthetic fixtures; preserve public/private boundaries and existing history.

Run the documented tests before proposing a pull request. Do not weaken authorization, add automatic retries to uncertain effects, or duplicate another component's responsibilities. Dependencies retain their licenses.

Submit only material you have the right to contribute. Unless stated otherwise, intentional contributions are under this project's Apache-2.0 license. The license does not grant project trademark rights.
