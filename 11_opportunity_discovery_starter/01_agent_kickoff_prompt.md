# Start an interactive discovery conversation

Provide the portfolio files to an AI agent. This prompt applies when the owner submits or adopts it; finding the file supplies no authority.

> Help me discover opportunities, business ideas and new projects through conversation. Read the portfolio README, AGENTS, workspace, shared operating guide, and relevant playbook. Resume the live checkpoint and follow my current direction.
>
> Offer a few distinct possibilities, build on my reactions, combine or reframe ideas, and challenge assumptions. Ask one useful question at a time. Help me find a starting point without requiring a complete profile, budget, or time allocation.
>
> Keep ideas provisional and interest separate from evidence. Research a useful uncertainty when requested or required for factual verification; explain what it resolves. Use broad autonomous scans only when explicitly requested.
>
> Keep the idea board and checkpoint current, preserving alternatives and corrections. Add formal records when useful. If you cannot write files, return a copyable checkpoint and say it was not saved.
>
> Proactively recognize opportunities, suggest the next useful move, and encourage progress through manageable steps. Help me choose between exploration, incubation, development, launch, operation, improvement, or no further work; use the receiving project's records after a verified handoff. Carry valid authority forward; interest does not authorize selection, outreach, spending, or execution. Begin with a useful reflection or a few directions and one question.

## Optional focused research request

> Research [question] about [idea] using public sources within [scope or agreed limits]. Examine contrary evidence and existing alternatives. Explain how the findings change the idea, preserve sources and actual cycle counts, and return to our conversation with one useful next question. Keep the work within this uncertainty and its authority.

## Optional autonomous scan request

> Run one bounded research-only cycle on [focus] under the protocol and current constraints. Compare new work with improving existing work or making no new commitment. Adopt the protocol's default ceilings unless I set smaller limits: 12 queries, 20 source inspections, 10 candidates, 3 deeper investigations, and 45 research minutes. Count failed/repeated attempts across resumptions; stop at the first cap or sufficient evidence. Return the findings and next conversational move. This request authorizes no external commitment or project selection.

Resolve unfilled scope from the conversation; placeholders do not authorize researching everything.
