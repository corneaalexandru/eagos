# Evidence Index

## Purpose

Navigate source evidence, semantic derivatives, and the authoritative [Evidence Register](../00_control/04_evidence_register.md).

## Structure

- `10_raw/` — original received or externally generated evidence; preserve filenames where provenance matters
- `20_derived/` — numbered extracts, normalized data, summaries, screenshots, and other project-generated derivatives

## Creation rule

Create an evidence file only when it supports or contradicts a material claim, assumption, hypothesis, decision, risk, task, output, or gate. Index originals rather than renaming them when preservation is required.
