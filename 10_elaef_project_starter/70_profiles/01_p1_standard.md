# P1 — Standard Project

Use for collaborative or commercially relevant work.

## Required implementation

- Project hub and `AGENTS.md`
- Explicit authoritative control records
- Stable IDs for material records
- Activity and dependency network
- Evidence, decision, risk, gate, and material-change controls
- Project Activation Gate
- Complete `50_handover/` reference and continuity module
- Receiver acceptance for material handovers
- Designated write owners
- Version history or recoverable backup

The starter pack defaults to P1 structure.

Files may be merged when authoritative ownership remains clear and the merge reduces administration without weakening retrieval, access, or traceability.
